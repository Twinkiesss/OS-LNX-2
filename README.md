# VTSH — учебная командная оболочка

## Описание проекта

VTSH — учебная командная оболочка, реализованная на языке C для Linux.

Проект разработан в рамках лабораторной работы LNX-2. Реализован вариант:

**clone, bg, ;, NPROC**

Оболочка поддерживает запуск внешних программ, встроенные команды, последовательное и фоновое выполнение команд, а также настройку ограничения количества процессов.

## Реализованные возможности

### 1. Запуск процессов через clone

Для создания дочерних процессов используется системный вызов `clone()`.

Для каждого дочернего процесса выделяется отдельный стек размером 1 МБ. Используется флаг `SIGCHLD`. Флаги совместного использования адресного пространства и других ресурсов не устанавливаются.

После создания дочернего процесса родительская оболочка освобождает выделенный стек.

### 2. Фоновое выполнение команд

Для запуска команды в фоновом режиме используется оператор `&`.

Пример:

```bash
sleep 5 &
echo shell continues
```

Оболочка не ожидает завершения фоновой команды и продолжает принимать следующие команды.

Информация о фоновых процессах хранится в списке заданий. Для проверки завершения процессов используется `waitpid()` с флагом `WNOHANG`.

Завершившиеся фоновые процессы собираются оболочкой, что позволяет избегать накопления зомби-процессов.

При завершении оболочки через `exit` или при достижении конца входного потока незавершённые фоновые процессы не ожидаются и не завершаются принудительно. Они продолжают работу независимо от оболочки, а записи об этих заданиях освобождаются.

### 3. Последовательное выполнение команд

Для последовательного выполнения нескольких команд используется оператор `;`.

Пример:

```bash
echo first ; echo second ; echo third
```

Команды выполняются последовательно. Следующая команда запускается независимо от кода завершения предыдущей.

Операторы `;` и `&` должны быть отделены от слов пробелами.

### 4. Ограничение количества процессов NPROC

Для настройки ограничения используется ресурс `RLIMIT_NPROC`.

Значение ограничения задаётся переменной окружения `VTSH_NPROC_LIMIT`.

По умолчанию используется значение `64`.

Пример запуска оболочки с ограничением:

```bash
VTSH_NPROC_LIMIT=32 ./build/bin/vtsh
```

Ограничение устанавливается в дочернем процессе до запуска внешней программы с помощью `getrlimit()` и `setrlimit()`.

Изменяется мягкий лимит `rlim_cur`, а жёсткий лимит сохраняет унаследованное значение. Лимит самой оболочки не изменяется.

Если получить или установить ограничение не удаётся, дочерний процесс завершается с ошибкой, не запуская целевую программу.

Ограничение `RLIMIT_NPROC` применяется к количеству процессов с соответствующим реальным идентификатором пользователя. Для привилегированных пользователей Linux это ограничение может не действовать.

## Дополнительные возможности

Реализованы встроенные команды:

- `cd` — смена текущего каталога оболочки;
- `exit` — завершение оболочки.

Для запуска внешних программ используется `execvp()`. Это позволяет запускать команды по имени с поиском исполняемого файла в `PATH`, а также передавать аргументы и окружение.

Реализована обработка ошибок создания процессов, ожидания завершения, настройки ограничений и запуска программ.

## Поддерживаемый синтаксис

Оболочка поддерживает:

- запуск внешних команд;
- передачу аргументов через пробелы;
- последовательное выполнение через `;`;
- фоновый запуск через `&`;
- встроенные команды `cd` и `exit`.

Ограничения синтаксиса:

- слова разделяются пробельными символами;
- операторы `;` и `&` должны быть отдельными токенами;
- кавычки и группировка аргументов не поддерживаются;
- конвейеры и перенаправления ввода-вывода не реализованы.

При обнаружении некорректного синтаксиса оболочка выводит сообщение об ошибке.

## Сборка проекта

Необходимые инструменты:

- Linux;
- GCC или совместимый C-компилятор;
- CMake;
- Python 3 для запуска тестов.

Сборка выполняется командами:

```bash
cmake -S . -B build
cmake --build build
```

Исполняемый файл создаётся по пути:

```text
build/bin/vtsh
```

## Запуск

Обычный запуск:

```bash
./build/bin/vtsh
```

Запуск с заданным ограничением NPROC:

```bash
VTSH_NPROC_LIMIT=32 ./build/bin/vtsh
```

## Тестирование

Для запуска автоматических тестов выполните:

```bash
ln -sf build/bin/vtsh shell
python3 -m unittest discover -s test -p "test_*.py" -v
```

Тесты проверяют базовые возможности оболочки, в том числе:

- обработку пустой команды;
- выполнение `echo`;
- выполнение нескольких команд;
- операции с файлами;
- обработку некорректных путей;
- взаимодействие со стандартным вводом;
- запуск вложенных оболочек.

Тесты перенаправления ввода-вывода относятся к дополнительной функциональности и не входят в выбранный вариант задания.
